Cách nhanh nhất: tiện ích trình duyệt Khuyên dùng

Dùng tiện ích để chuyển phiên đăng nhập muse.ai từ trình duyệt của bạn sang dịch vụ. Không cần dùng dòng lệnh.
1
1. Tải tiện ích
Tải và giải nén vào một thư mục dễ tìm.
⬇ Tải tiện ích trình duyệt
2
2. Nạp tiện ích vào trình duyệt
Chrome, Edge và các trình duyệt tương thích Chromium đều dùng được:
  1. Mở chrome://extensions
  2. Bật Chế độ dành cho nhà phát triển
  3. Chọn Tải tiện ích đã giải nén
  4. Chọn thư mục đã giải nén ở bước 1
3
3. Đăng nhập và nhập tài khoản
Đăng nhập https://muse.ai/, sau đó mở tiện ích ngay trên trang này. Địa chỉ dịch vụ và API key sẽ tự điền; bạn chỉ cần chọn “Lấy Cookie và thêm tài khoản”.

Cách khác: nhập Cookie thủ công Nâng cao

Nếu không dùng tiện ích, hãy lấy Cookie trong công cụ dành cho nhà phát triển của trình duyệt. Chọn tab Network, sao chép dòng cookie: trong Request Headers.
  1. Mở và đăng nhập https://muse.ai/
  2. Nhấn F12, chọn tab Network
  3. Nhấn F5 để tải lại trang
  4. Chọn một yêu cầu tới muse.ai
  5. Trong Headers → Request Headers, tìm dòng cookie:
  6. Sao chép toàn bộ nội dung sau dấu hai chấm, bắt đầu từ hatch_sess=
  7. Dán Cookie vào ô nhập bên dưới
Lưu ý: sao chép dòng cookie: trong Request Headers, không dùng set-cookie trong Response Headers.

Hoặc dùng script Python để đăng nhập bằng cửa sổ trình duyệt riêng. Không cần cài thêm thư viện.

Tạo ảnh thử POST /v1/images/generations

Gửi yêu cầu tạo ảnh thật tới muse.ai; thường mất 10–30 giây.

Tạo video thử POST /v1/videos

Tác vụ chạy nền, thường mất 60–120 giây. Trang sẽ tự cập nhật tiến độ.

Hướng dẫn kết nối

API tương thích OpenAI. Trong ứng dụng của bạn, chỉ cần đổi base_url và api_key.
Địa chỉ API: —

1. Model khả dụng

Mã modelChức năngEndpoint
muse-sparkChat / lập trình (có streaming)POST /v1/chat/completions
POST /v1/responses
muse-imageTạo ảnh / chỉnh sửa ảnhPOST /v1/images/generations
muse-videoTạo video / video từ ảnhPOST /v1/videos → GET /v1/videos/{id}
Các model Muse có chức năng tương ứng: Muse Spark (chat / lập trình), Muse Image (tạo ảnh), Muse Video (tạo video). Trang muse.ai tự chọn model, nên các tên phổ biến như gpt-4o, claude-sonnet-4 hoặc dall-e-3 sẽ được ánh xạ tự động.

2. Chat / lập trình

Sao chép# Không streaming
curl -X POST "BASE/v1/chat/completions" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"muse-spark","messages":[{"role":"user","content":"Viết thuật toán quicksort bằng Python"}]}'

# Streaming: thêm "stream":true để nhận SSE chuẩn

3. Tạo ảnh (curl)

Sao chépcurl -X POST "BASE/v1/images/generations" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Một chú chó Shiba đội mũ phi hành gia","size":"1:1","response_format":"url"}'

# Kết quả
{"created":1790148495,"data":[{
  "revised_prompt":"Một chú chó Shiba đội mũ phi hành gia",
  "url":"http://your-server:18610/v1/media/xxxx.webp",
  "kind":"image","bytes":23860}]}

# url là địa chỉ đầy đủ để hiển thị/tải; /v1/media/* không cần xác thực.
# Để nhận base64, đặt "response_format":"b64_json".

4. Tạo video (curl, chạy nền)

Sao chép# ① Tạo tác vụ
curl -X POST "BASE/v1/videos" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Một chú mèo đi trên bãi cỏ","duration":5,"size":"16:9"}'
# → {"id":"task_xxx","status":"queued"}

# ② Kiểm tra kết quả
curl "BASE/v1/videos/task_xxx" -H "Authorization: Bearer $MUSE2API_KEY"
# → {"status":"succeeded","result":{"url":"/v1/media/xxx.mp4"}}

5. Python (tương thích OpenAI SDK)

Sao chépfrom openai import OpenAI
import time

client = OpenAI(base_url="BASE/v1", api_key="m2a_...")

# Tạo ảnh
r = client.images.generate(model="muse-image", prompt="Một chú chó Shiba đội mũ phi hành gia")
print(r.data[0].url)

# Tạo video (dùng API riêng vì tác vụ chạy nền)
  import requests
t = requests.post("BASE/v1/videos", json={"prompt":"Mèo đang đi","duration":5},
                  headers={"Authorization":"Bearer m2a_..."}).json()
while True:
    s = requests.get(f"BASE/v1/videos/{t['id']}",
                     headers={"Authorization":"Bearer m2a_..."}).json()
    if s["status"] in ("succeeded","failed"): break
    time.sleep(5)
print(s)

7. Xác thực

Ngoại trừ /healthz, /readyz và /v1/media/*, các API khác cần Authorization: Bearer <API Key>. Cấu hình key trong MUSE2API_KEY ở file `.env`.

8. Kết nối ứng dụng và agent

Ứng dụng hỗ trợ endpoint tương thích OpenAI chỉ cần ba thông tin sau:
Thông tinGiá trị
Địa chỉ APIhttp://<IP-hoặc-tên-miền>:18610/v1
API keym2a_... (hiển thị ở đầu trang)
Modelmuse-spark
Có thể dùng nhiều tên model: các tên thông dụng (gpt-4o, gpt-5, claude-sonnet-4, deepseek-chat, gemini-2.5-pro) được ánh xạ tự động; muse.ai sẽ chọn khả năng phù hợp.

Loại ứng dụngAPI sử dụngTrạng thái

Giới hạn về tool calling: Muse chưa hỗ trợ tạo lời gọi công cụ. Agent cần tự đọc/ghi tệp hoặc chạy lệnh chưa dùng được. Chat, lập trình, dịch, tóm tắt, tạo ảnh và video vẫn hoạt động. Nếu gửi trường tools, API sẽ bỏ qua và xử lý như hội thoại thông thường.
